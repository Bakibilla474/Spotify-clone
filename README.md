# Spotify-Inspired Web Player UI

A static music-player interface recreation built with HTML and CSS. This project explores a dark dashboard layout, sidebar navigation, playlist cards, and a fixed playback bar.

## Interface sections

- Navigation and library sidebar
- Recently played and featured chart cards
- Sticky content navigation
- Playback bar layout with a progress indicator

## Run locally

Open `index.html` in a modern browser. The project has no build step.

## Scope

This is a visual UI demo. Search, navigation, account controls, playlist actions, and playback are presentation only; the page does not connect to Spotify or play audio. It is not affiliated with or endorsed by Spotify.
